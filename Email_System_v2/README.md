# Email Management System *(A-MAIL v2)*

A modern email management application built using **JavaFX, JDBC, and MySQL**.

A-MAIL v2 is the second iteration of the project, redesigned from the original console-based implementation into a graphical desktop application with an improved user experience, account management, and email organization features.

---

## Features

### 🔐 Authentication

* User registration
* Secure login system
* Account deletion support

### 📨 Email Management

* Compose emails
* Inbox view
* Sent mail view
* Draft management
* Spam folder support

### 👤 User Experience

* Modern JavaFX interface
* Responsive dashboard layout
* Email viewer panel
* Scrollable inbox
* Interactive sidebar

### 🗄 Database Integration

* MySQL database backend
* Persistent email storage
* User account management
* JDBC connectivity

---
