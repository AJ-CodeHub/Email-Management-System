# 📧 A-MAIL

An email management system built using Java, JDBC, MySQL, and JavaFX.

This repository contains two versions of the project:

## A-MAIL v1
- Console-based application
- User authentication
- Email composition
- Inbox management
- JDBC + MySQL backend

Location:
Email_System_v1/

---

## A-MAIL v2
- Modern JavaFX interface
- Inbox, Sent, Drafts, Spam
- Email viewer
- Account deletion
- Scrollable inbox
- Improved UI/UX

Location:
Email_System_v2/

---

## Tech Stack

- Java
- JavaFX
- JDBC
- MySQL
